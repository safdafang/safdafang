### 🧾 Featured project — [eracun-hr](https://github.com/wozimon/eracun-hr)

A Python library to **build, read and validate Croatian eRačun** documents —
UBL 2.1 invoices according to EN 16931 and CIUS-HR (**Fiskalizacija 2.0**),
checked with the official XSD and Schematron rules of the Tax Administration.

[![CI](https://github.com/wozimon/eracun-hr/actions/workflows/ci.yml/badge.svg)](https://github.com/wozimon/eracun-hr/actions/workflows/ci.yml)
![Python](https://img.shields.io/badge/python-3.11%20%E2%80%93%203.14-3776AB?logo=python&logoColor=white)
